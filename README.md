# Radio Sirens

<p align="center">
  <img src="logo.png" width="350" title="Logo">
</p>

Repository with scripts to generate mock BBH and HI intensity-mapping data, run the radio-siren cosmological analyses using the icarogw-HI branch ([link](https://github.com/icarogw-developers/icarogw/tree/HI)), and reproduce all the figures in the corresponding paper ([link](https://arxiv.org/abs/2605.12606)). It supports simulations, inference, validation tests, and plotting for the ET–SKA synergy study for H0 inference.

The starting and output dataset of this repository is released on Zenodo:
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20582389.svg)](https://doi.org/10.5281/zenodo.20582389)

The Zenodo record provides a summary and overview of the scripts with the instructions to reproduce the paper's results.
